# 🧮 Cálculo de Polinomios - Doble División Sintética

Programa diseñado para encontrar las raíces de un polinomio empleando el método numérico de **Doble División Sintética**. Este algoritmo permite reducir el grado del polinomio y aproximar sus soluciones de manera eficiente.

---

## 🚀 Funcionalidades Clave

* **Evaluación Polinomial:** Ingreso de coeficientes y grado del polinomio a evaluar.
* **Algoritmo Numérico:** Aplicación iterativa de la doble división sintética para la obtención de factores y residuos.
* **Cálculo de Raíces:** Determinación de raíces reales y aproximaciones numéricas.
* **Lógica y Ejecución:** Incluye el pseudocódigo estructurado y el código fuente ejecutable.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje de Programación:** C / C++ (Compilado con Dev-C++)
* **Lógica / Algoritmo:** PSeInt (Pseudocódigo)
* **Entorno de Desarrollo:** Dev-C++ IDE
